# CorrerIA

O contato da CorrerIA Code no WhatsApp, pela API oficial da Meta: as pessoas da casa perguntam e os apps da família respondem com a IA.

- Perguntas sobre as finanças respondidas pelo GerencIA, com os seus dados
- Fotos de notas, prints e faturas em PDF lidos pela IA (no GerencIA, ficam para conferir no Início)
- Áudio pela fala para texto do Home Assistant
- Só os números das pessoas da casa recebem resposta
- Webhook em https com o certificado do Duck DNS; a tela fica só no painel do Home Assistant
- Testar uma pergunta sem passar pelo WhatsApp e as últimas mensagens na tela
- Tema claro e escuro
